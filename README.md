# 量潮搜索工程

## 概述

信息量涨起来之后，我们开始找不到东西了：要管理信息，也要检索信息。本域把「找得到」做成一件工程。

## 定位：检索索引侧

一条线划开事实源与检索索引：事实源的内容归其所属领域，索引与检索服务归本域。判据一句话——这条内容删掉后能否从别处重建？能，是索引侧，归本域；不能，是事实源，归其领域。

本域管从「信息在哪」到「把它取出来」这一段：可索引化、索引的建立与更新、查询解析、召回、排序、质量评测。信息管理里属于本域的是为检索服务的那部分（可索引化、检索用元数据、索引的新鲜度与一致性）；信息的定义（主数据、本体）归元工程，知识抽取与图谱建模归知识工程。

与元工程的三层互补：元工程管什么是真的、怎么定义，本域管怎么把它找出来。
